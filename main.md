7. В чем разница между циклами for, while и do-while? В каких случаях лучше использовать каждый из них?

        for — используется, когда заранее известно количество повторений / счётчик
        while — используется, когда количество повторений неизвестно, но есть условие / пока условие истинно
        do-while — выполняется минимум один раз, даже если условие ложное / сначала делает, потом проверяет
